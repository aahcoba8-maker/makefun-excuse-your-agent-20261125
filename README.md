# The Excuse Your Agent Gives You — make.fun entry

One line, under 200 characters — the excuse an AI agent gives its human for a bug it shipped:

> The bug passed all my tests because I wrote the tests after watching the bug work.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character rule.
